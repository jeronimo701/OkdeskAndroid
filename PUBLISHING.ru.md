# Публикация OkdeskAndroid 0.2.34

Дата: 2026-10-22. Репозиторий private; доступ к исходникам и APK имеют владелец и приглашённые пользователи GitHub. Ссылка сама по себе не предоставляет доступа. API-токены, пароли, keystore, local.properties, кэши Gradle, старые APK и рабочие данные в Git не включаются.

Версия APK: 0.2.34, сборка debug, для ограниченной проверки. Это не подписанный production-релиз. APK подписан существующим локальным Android debug-сертификатом; сам keystore не распространяется. Установка и работа на реальном устройстве в этой передаче не проверялись. Для production нужна отдельная подпись и аппаратная проверка.

Среда: JDK 17, Android SDK Platform 35, Build Tools 35.0.0, Gradle 8.11.1, Android Gradle Plugin 8.9.2. Команда проверки:

```powershell
$env:ANDROID_HOME = 'C:/path/to/Android/Sdk'
.\gradlew.bat --offline lintDebug assembleDebug --no-daemon --console=plain
```

В текущей среде первая попытка остановилась на Java Unix-domain loopback. Установка JVM-параметра jdk.net.unixdomain.tmpdir на существующую короткую локальную папку устранила ошибку. Этот машинный путь не записывается в настройки проекта. При первой сборке без локального кэша уберите --offline.

Собственная лицензия действует только в области LICENSE-SCOPE.md. Исходные тексты сторонних лицензий и notices сохранены.

Из копии app/src/main/assets/okdesk.user.js удалён фиксированный URL вложения с токеном: вместо него оставлен адрес главной страницы справочного сайта. Поэтому версия повышена с 0.2.33 (code 35) до 0.2.34 (code 36). Остальная логика приложения не изменялась. Исходная папка пользователя и прежний APK не менялись.

Существующий тест scripts/check-recent-searches.cjs прошёл: лимит, порядок, дедупликация, срок хранения, некорректные данные, поиск и возврат, очистка и отсутствие переполнения на 280/360/412 px. Он использует локальные ответы и Playwright из среды Codex; живой Okdesk не изменялся.

Итог: lintDebug и assembleDebug PASS; ошибок lint нет, предупреждений 12. Их список: DefaultLocale, MonochromeLauncherIcon, ObsoleteSdkInt, SetJavaScriptEnabled, SetTextI18n, UnusedAttribute. Предупреждения существующего кода не исправлялись в рамках переноса.
