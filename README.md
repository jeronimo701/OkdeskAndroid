# Okdesk Mobile

Мобильная оболочка Okdesk и каталогов POScenter с собственными встроенными помощниками.

**[Скачать 0.2.34](https://github.com/jeronimo701/OkdeskAndroid/releases/download/v0.2.34/OkdeskMobile-0.2.34-debug.apk) · [Описание релиза](https://github.com/jeronimo701/OkdeskAndroid/releases/tag/v0.2.34) · [Все выпуски](https://github.com/jeronimo701/OkdeskAndroid/releases)**

| Платформа | Версия | Файл |
| --- | --- | --- |
| Android 10+ | 0.2.34 | `OkdeskMobile-0.2.34-debug.apk` |

## Возможности

**Okdesk под рукой.** Мобильный список и карточки заявок, переключение в полную версию и обратно.

**Каталоги POScenter.** Разделы Optposcenter и FS Poscenter, поиск и работа с файлами.

**Удобная навигация.** История поиска, загрузка вложений, выбор файлов, светлая и тёмная темы.

**Хранение токена.** Шифрование API-токена через Android Keystore; резервное копирование приложения отключено.

## Установка

Установите APK и войдите в свою учётную запись Okdesk. Без API-токена доступен обычный сайт с помощниками оболочки. Для API-функций добавьте личный токен через настройку API и выберите рабочую группу. Сессия приложения отдельна от браузера. Сборка настроена на `shtrih-m.okdesk.ru`.

## Статус выпуска

APK подписан debug-сертификатом. Сборка и lint ранее прошли: 0 ошибок; тест истории поиска и вёрстки выполнен на локальных ответах. Вход, отправка комментариев и загрузка файлов на реальном телефоне при открытии репозитория не проверялись. Встроенные скрипты закреплены в APK: обновление Tampermonkey не обновляет приложение. Не добавляйте токены и пароли в исходники.

Контрольные суммы и сопроводительные лицензии находятся в файлах релиза.

## Сборка из исходников

```powershell
.\gradlew.bat lintDebug assembleDebug --no-daemon --console=plain
```

JDK 17, Android SDK 35. Подробности поведения и границ доступа — [docs/TECHNICAL.md](docs/TECHNICAL.md). Исторический отчёт сборки — [PUBLISHING.ru.md](PUBLISHING.ru.md).
