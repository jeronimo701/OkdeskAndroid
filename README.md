# Okdesk Mobile

Android-клиент Okdesk и каталогов POScenter с адаптивными карточками заявок и поддержкой складных экранов.

## Что умеет

**Два окна вместо одного.** На широком экране список заявок остаётся слева, открытая карточка — справа. Список и карточка прокручиваются независимо.

**Выбор компоновки.** Автоматический режим, две панели или одна панель. На узком экране приложение возвращается к одной колонке.

**Поддержка сгиба.** Элементы обходят шарнир: при вертикальном сгибе список и заявка разделены, при горизонтальном — переписка сверху, ответ и действия снизу.

**Черновик остаётся на месте.** Переключение компоновки сохраняет введённый ответ и выбранные вложения в открытой карточке. Это не восстановление после завершения процесса.

**Каталоги под рукой.** Встроенные разделы Optposcenter и POScenter Files, поиск, файлы, тёмная и светлая темы.

## Что нового

- Добавлена двухпанельная работа со списком и карточкой заявки на широких экранах.
- Добавлена обработка положения сгиба и отступов вокруг шарнира.
- При изменении компоновки сохраняются текущий ответ и выбранные вложения.
- Список в режиме «ноутбука» разделяет результаты и инструменты поиска; плавность переходов можно отключить.

## Установка

Установите APK, откройте приложение и войдите в Okdesk. Обычный сайт работает без API-токена; дополнительные API-функции настраиваются через меню. Токен хранится с шифрованием Android Keystore. Сборка настроена на `shtrih-m.okdesk.ru`.

| Файл | Скачать |
|---|---|
| `OkdeskMobile-0.2.35-debug.apk` | [APK](https://github.com/jeronimo701/OkdeskAndroid/releases/download/v0.2.35/OkdeskMobile-0.2.35-debug.apk) |

Сборки подписаны отладочным сертификатом. Для обновления поверх прежней установки подпись должна совпадать. Контрольные суммы — `SHA256SUMS.txt` в релизе.

## Ограничения и проверка

На физическом складном устройстве и с рабочими заявками новая версия при публикации не проверялась. Встроенные скрипты закреплены в APK: обновление Tampermonkey не обновляет клиент.

Проверки этой публикации, подписи и совпадение APK с исходными сборками — [PUBLICATION-VALIDATION.md](PUBLICATION-VALIDATION.md). Подробности поведения и исторические проверки разработки — [docs/TECHNICAL.md](docs/TECHNICAL.md).

## Сборка

JDK 17 и Android SDK 35. Настройте `ANDROID_HOME` или локальный `sdk.dir`.

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```
